{{- else }}

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "nimbus.fullname" . }} 3000:{{ .Values.service.port }}
  http://localhost:3000
{{- end }}

Then create the first account; it becomes the admin.
{{- if and (not .Values.secrets.existingSecret) (not .Values.secrets.encryptionKey) }}
{{- if .Values.persistence.enabled }}

JWT_SECRET and ENCRYPTION_KEY were not set, so Nimbus generates them and keeps them in the uploads
volume ({{ .Values.persistence.existingClaim | default (printf "%s-uploads" (include "nimbus.fullname" .)) }}). Back that volume up: without ENCRYPTION_KEY, saved integration credentials
can't be read.
{{- else }}

WARNING: persistence is off and no encryptionKey is set. Nimbus generates new secrets on every
restart, which logs everyone out and makes saved integration credentials unreadable.
Set secrets.jwtSecret and secrets.encryptionKey, or turn persistence on.
{{- end }}
{{- end }}
